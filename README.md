# PRISM

**Property Recommendation & Interior Space Matcher**

> An AI-powered property platform that learns what users are looking for based on Swipe to like or swipe to dislike similar to that of Tinder's UI , recommends suitable properties, analyses interiors, and helps visualise furniture and spaces.
